# Pianostämning

Webbapp för att stämma ett akustiskt piano med hänsyn till inharmonicitet, med loggbok.
Körs helt i webbläsaren. Data sparas lokalt (localStorage) på den enhet du använder.

## Publicera på GitHub Pages

1. Skapa ett nytt repo på github.com (t.ex. `pianostamning`), publikt om du har gratiskonto.
2. Ladda upp `index.html` (och `.nojekyll`) till repots rot via "Add file" > "Upload files".
3. Gå till Settings > Pages. Välj "Deploy from a branch", branch `main`, mapp `/ (root)`. Spara.
4. Efter någon minut finns sidan på `https://<ditt-användarnamn>.github.io/pianostamning/`.
5. Öppna adressen i mobilens webbläsare och tillåt mikrofonen. Lägg till på hemskärmen för snabb åtkomst.

Mikrofon kräver HTTPS, vilket GitHub Pages ger automatiskt.
